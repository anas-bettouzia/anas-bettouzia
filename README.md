### Featured Project

**Jira Migration AI Analyzer** · *Final-year engineering project at Spectrum Groupe*

An AI-powered platform that automates the pre-migration audit of Jira Data Center instances before moving to Jira Cloud.

- 6 Flask microservices behind an API Gateway, with asynchronous processing (Redis, RQ)
- Hybrid analysis engine: deterministic rules + RAG (ChromaDB) + LLMs (Gemini, Ollama)
- Migration score, blocker detection and recommendations, exported as bilingual PDF/JSON reports
- 13 Docker containers, Bamboo CI/CD, SonarQube quality gate, Prometheus and Grafana monitoring

[View the code](https://github.com/anas-bettouzia/jira-migration-project---AI-ANALYZER---PFE-PROJECT) · [Read the case study](https://anas-bettouzia.vercel.app/#work)
